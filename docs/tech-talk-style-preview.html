ESP32-BOX / EP.1 原理篇
Principle · 功放

一串整数，怎么变回空气的振动

D 类功放的核心思想：不做线性放大，只做开关 —— 然后让喇叭线圈自己滤波

传统 AB 类：线性放大

DAC 把数字变成模拟电压 → 功放线性放大到能推喇叭。

输出管工作在线性区
管子始终「半导通」参与分压
分掉的电压 → 全部变成热量
效率 ≈ 50%

D 类：只开关，不放大

输出管只有两种状态：彻底导通、彻底关断。

完全导通 → 管压降 ≈ 0 → 功耗 ≈ 0
完全关断 → 电流 ≈ 0 → 功耗 ≈ 0
效率 > 90%，几乎不发热

两个关键机制：PWM 调制 + 喇叭线圈自滤波

大信号 → 占空比高
▔▔▔▔▔▁▔▔▔▔▔▁▔▔▔▔▔▁

小信号 → 占空比低
▔▁▁▁▁▁▔▁▁▁▁▁▔▁▁▁▁▁
喇叭线圈 = 天然低通滤波器
电感阻碍电流突变
→ 高频方波被平滑成模拟波形
→ 不需要独立 DAC 芯片
ESP32-BOX / EP.1 原理篇
Principle · I2S

PCM 怎么从芯片传到功放

音频对总线的特殊要求是「等时性」—— 不只要送到，还要精确准时地送到

BCLK · 位时钟

每个上升沿 = 划分比特边界。

44100 × 16 × 2
= 1.4112 MHz

LRC · 帧同步

划分声道边界，低左高右。

频率 = 采样率
= 44100 Hz

DIN · 数据

串行逐位送出，高位在前。

1 个 16 位样本
= 16 个 BCLK 周期

三根线的配合：时间信息在时钟里，不在数据里
