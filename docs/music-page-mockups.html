摇杆左右在三个子页间切换，与首页「时钟/天气」双页轮换的交互一致。每页只专注一件事，都不拥挤。 封面 88×88 圆角方块（无封面时画黑胶唱片矢量占位）；歌词页当前句大号白字、前后句渐隐；频谱页复用已有的 16 条 FFT 柱。

⚠ 落地前需要确认的两件事

1. 数据来源：当前 BluetoothA2DP 是桩实现（ESP32-S3 无 Bluetooth Classic），封面、歌词、曲目全无真实音源。 需选择：① SD 卡放 MP3 + 同名 .lrc + 封面图；② 联网从 API 拉取；③ 先做 UI 骨架用假数据验证布局。

2. 中文字库：现有字库是按需生成的 87 个汉字，歌词含任意汉字必然大量缺字。 需升级为「全量 3500 常用字（约 448KB，4bpp）放 SPIFFS，运行时按需加载字形」。 SPIFFS 有 3.4MB 空间，容量充足，但需要改字库架构并单独烧录文件系统镜像。
