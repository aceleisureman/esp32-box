频谱可视化方案（动态预览）

四套方案均按 320×240 实机能力设计（RGB565 / 增量重绘 / 无 alpha 混合依赖）。动画为模拟音乐数据。

方案 A · 镜像水面（当前版精修）

实现成本低24 条胶囊柱 + 水面倒影 + 白色峰值帽坠落。 横向蓝→青→紫渐变。稳重耐看，信息区完整保留。

方案 B · 中心声波（对称绽放）

实现成本低柱子以水平中线为轴上下对称伸展， 像声波从中心炸开。中线细亮线贯穿，低频在中间、高频在两侧（对称频谱排布）。 动感最强、最像"声音的形状"。

方案 C · 复古 LED 矩阵

实现成本低WinAmp / 音响均衡器的经典点阵风： 每柱由分段小方块组成，绿→黄→红能量分层，峰值块悬停坠落。 复古味十足，和翻页时钟的拟物气质呼应。

方案 D · 环形律动

实现成本中频谱柱沿圆环向外辐射，中心是旋转唱片 （复用现有黑胶占位图）。整体像一枚会呼吸的音乐徽章，视觉最独特； 径向线段用粗线绘制，增量重绘按扇区处理。
